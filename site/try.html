2

Every glasses screen, in Even's simulator

2 minutes. Needs Node.js 20 or newer.

  1. Run Even's official G2 simulator with our hosted app in tour mode: 
    npx @evenrealities/evenhub-simulator "https://reins-jhyz.onrender.com/glasses/?tour"
  2. Tap to step through every screen: a safe payment, a poisoned address, an injected amount, an impostor agent, a stolen key, the kill.
  3. The simulator's phone panel shows the live phone page next to it.

3

The real thing, on TON testnet

10 minutes. Real wallets, free test money.

  1. Start the app without the tour: 
    npx @evenrealities/evenhub-simulator "https://reins-jhyz.onrender.com/glasses/"
  2. In the phone panel, Create my vault and write down the 24 words.
  3. Copy address, then get free test GRAM from @testgiver_ton_bot in Telegram and send it there.
  4. Connect an agent with the code under Connect an agent: 
    git clone https://github.com/miracle352/reins && cd reins && npm install
REINS_LINK=YOUR-CODE npx tsx tools/agent-cli.ts my-bot connect
    Approve it on the glasses. Then ask it to pay someone and watch the lens: 
    npx tsx tools/agent-cli.ts my-bot pay 0QDKb9AkUSCDRhUkbJdsRs5RsI0uLuQF45gSL4jTG6hMpt8S 0.05 "Hotel deposit, 0.05 GRAM"
  5. Optional: tap Link Telegram on the phone page to get the alerts in @reins_m_bot.
  6. To use Claude Code, Hermes or Codex as the agent instead, see the agent guide.
